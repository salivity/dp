DisplayPort Timings with Retro Upscalers and OSSC Pro

Modern retro console upscalers like the OSSC Pro face a significant challenge when interfacing classic hardware with modern digital displays: vintage consoles output non-standard, fluctuating refresh rates that violate contemporary broadcast specifications. This article explains how DisplayPort addresses variable display timing profiles from retro consoles, focusing on packetized data transmission, VESA Adaptive-Sync, pixel clock decoupling, and how devices like the OSSC Pro leverage these mechanisms to provide stutter-free, zero-lag video output.

The Retro Timing Problem

Vintage consoles like the Super Nintendo, Sega Genesis, and Sony PlayStation do not adhere to modern video standards such as fixed 59.94 Hz or 60.00 Hz. For example, a standard NTSC Super Nintendo outputs at approximately 60.098 Hz, while the Neo Geo outputs closer to 59.18 Hz.

When an upscaler uses traditional HDMI with a rigid, fixed-frequency pixel clock, modern monitors often lose sync, tear, drop frames, or force the upscaler to employ a frame buffer. Frame buffering introduces input latency and frame pacing anomalies (judder). To achieve genuine zero-lag line multiplication, the output device must pass these eccentric refresh rates directly to the monitor without temporal alteration.

Decoupled Transmission and Packetized Data

DisplayPort handles timing profiles fundamentally differently from legacy transmission methods. Traditional video interfaces tie the transmission clock directly to the pixel clock. DisplayPort, by contrast, operates on a packetized micro-packet protocol over fixed-rate physical lanes (such as 1.62 Gbps, 2.7 Gbps, or 5.4 Gbps).

Because the physical link rate is decoupled from the pixel clock, DisplayPort uses Main Stream Attribute (MSA) packets to transmit video timing information. The source calculates and transmits timing parameters using dynamic \(M\) and \(N\) multiplier values (\(M_{vid}\) and \(N_{vid}\)). The display uses these values to regenerate the pixel clock locally:

\[\text{Pixel Clock} = \text{Link Clock} \times \left(\frac{M_{vid}}{N_{vid}}\right)\]

This architecture gives DisplayPort the inherent ability to carry arbitrary, non-standard pixel clocks and blanking intervals. An upscaler can define exact horizontal and vertical blanking parameters to accommodate odd line counts (such as 262 lines for 240p) without disrupting the underlying high-speed digital link.

VESA Adaptive-Sync and Variable Refresh Rates

The most robust mechanism DisplayPort offers for retro upscaling is VESA Adaptive-Sync, which is built directly into the DisplayPort standard.

In standard fixed-refresh video, the vertical blanking interval (VBLANK) has a fixed duration. If a console outputs a frame early or late, it creates a timing mismatch. Under DisplayPort Adaptive-Sync:

  1. Dynamic VBLANK Extension: The monitor’s vertical blanking period becomes flexible. The display holds the last line of the frame until the OSSC Pro explicitly sends a vertical sync signal indicating that the retro console has finished drawing the frame.
  2. Elimination of Buffering: The upscaler can operate in pure line-multiplier mode. As the console draws each scanline, the upscaler processes and transmits it. When the console initiates a vertical retrace, the upscaler triggers the DP vertical sync, and the monitor immediately begins drawing the new frame.
  3. Pacing and Fluidity: Consoles with dynamic frame-pacing or irregular frame drops map 1:1 to the display panel's refresh cycle within its supported VRR range (for example, 40 Hz to 144 Hz), eliminating motion judder and frame-rate hitching entirely.

Resolution Transitions and Fast Resyncing

Certain retro games change resolutions dynamically between gameplay and menus (e.g., shifting between 240p progressive and 480i interlaced). On conventional displays, this causes a full renegotiation of the HDMI handshake, resulting in black screens that can last several seconds.

DisplayPort mitigates this behavior when paired with advanced FPGA-based upscalers like the OSSC Pro:

  • Link Layer Continuity: Because the DisplayPort Main Link stays synchronized at a fixed data rate, changes to active resolution and timing can be updated purely via MSA packets and stream metadata rather than re-training the physical link.
  • Instant Mode Switching: The OSSC Pro can pad or reconfigure vertical and horizontal sync intervals within the Adaptive-Sync profile, allowing compatible DisplayPort monitors to adapt instantly to line-count changes without losing the display signal.

By decoupling the data link from the video raster and offering native, hardware-level control over frame intervals through Adaptive-Sync, DisplayPort provides the precise timing flexibility required to present analog-era console video on modern digital displays with zero added latency and complete frame integrity.
