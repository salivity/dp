How OS Detects DisplayPort Monitor Power Off

When a user switches off a DisplayPort monitor using its physical power button, the operating system detects this event almost instantaneously through a dedicated hardware signal known as Hot Plug Detect (HPD). Unlike older display standards that often maintain a passive presence, DisplayPort treats a physical power-off as a full disconnection. Dropping the electrical signal on the HPD line prompts the graphics processing unit (GPU) to alert the display driver, which then triggers the operating system to unregister the monitor and reconfigure the desktop layout.

The Role of Hot Plug Detect (HPD)

DisplayPort cables contain a dedicated physical wire connected to Pin 18, designated as the Hot Plug Detect (HPD) line. When a monitor is powered on and connected, it supplies a continuous voltage (typically 3.3 volts) across this line back to the GPU. This voltage tells the graphics hardware that a display is connected, awake, and ready to communicate.

When the physical power switch on the monitor is toggled to "off," the display's internal controller ceases to supply this voltage, pulling the HPD line down to 0 volts (ground). In the DisplayPort standard, a low signal lasting longer than 2 milliseconds is defined as a disconnect event, ensuring that the GPU does not confuse brief signaling pulses with an actual disconnection.

The DisplayPort Configuration Data (DPCD) Link

DisplayPort communication relies on a bidirectional sideband channel called the Auxiliary (AUX) Channel. Alongside the HPD drop, the monitor shuts down its DisplayPort Configuration Data (DPCD) receiver. The DPCD holds crucial link status parameters, such as clock recovery and channel equalization states. When the physical power is terminated, the link status collapses entirely, preventing any further AUX channel handshake between the GPU and the monitor's internal scaler.

From GPU Interrupt to the Operating System

Once the GPU detects that the voltage on the HPD pin has fallen, the process moves up the software stack:

  1. Hardware Interrupt: The GPU generates a hardware interrupt signaling that a physical display connection has been severed.
  2. Graphics Driver Notification: The graphics driver catches this interrupt, checks the internal registers, and confirms the loss of the HPD line on that specific port.
  3. OS Display Subsystem Alert: The driver reports the removal to the operating system's display subsystem (such as the Desktop Window Manager in Windows, the Display Server in Linux, or WindowServer in macOS).
  4. Desktop Reconfiguration: The operating system unloads the Extended Display Identification Data (EDID) associated with that port. It removes the monitor from its active display list, redistributes open windows and application icons to any remaining active screens, and recalculates the virtual desktop bounds.

Because the DisplayPort specification defines power removal as a hardware-level disconnection, turning off the physical power button behaves identically to unplugging the DisplayPort cable from the graphics card.
