How Advanced Optimus MUX Routes Internal eDP Signals

NVIDIA Advanced Optimus relies on a dynamic hardware multiplexer (MUX) switch to automatically direct internal embedded DisplayPort (eDP) signals between the integrated GPU (iGPU) and the discrete GPU (dGPU). By dynamically switching which processor physically drives the laptop's internal panel, this technology balances battery efficiency and high-performance gaming without requiring a system reboot, unlocking low-latency graphics and proprietary display features on demand.

In traditional laptop designs running standard NVIDIA Optimus, the internal eDP lines are permanently wired to the iGPU. When demanding 3D applications run, the dGPU renders the frames and copies them through the PCIe bus to the iGPU's frame buffer, which then sends the signal to the eDP display. While this preserves battery life by keeping the dGPU off during basic tasks, the copy process introduces a memory bandwidth bottleneck, increases input latency, and often prevents features like NVIDIA G-Sync from operating on the internal screen. Alternatively, a manual hardware MUX switch solves the performance bottleneck by connecting the dGPU directly to the eDP panel, but it requires a full system restart to switch display modes.

The Advanced Optimus multiplexer solves these issues by acting as an electronic, high-speed physical switch positioned between the laptop panel's eDP receiver and the display controllers of both the iGPU and dGPU. Instead of relying on a static hardware trace, the eDP signal pathways run into this dynamic MUX. The system monitors running applications via software drivers, determining graphical requirements in real time.

When the user performs everyday tasks such as web browsing or document editing, the MUX routes the internal eDP lanes directly to the iGPU. The dGPU enters a low-power sleep state, maximizing battery life.

When a graphics-intensive application or game is launched, the driver signals the MUX to switch the physical eDP routing directly to the dGPU. Because the switch happens at the hardware controller level while maintaining signal synchronization, the change occurs seamlessly within a fraction of a second, without requiring a system reboot or closing active software.

By establishing this direct physical connection from the dGPU to the internal eDP panel, the Advanced Optimus multiplexer achieves three critical functions:

  • Eliminates the Hybrid Bottleneck: Frames render directly to the screen without passing through the iGPU or consuming system RAM bandwidth.
  • Reduces Input Latency: The removal of intermediate frame copying delivers lower latency and higher average frame rates.
  • Enables Native Display Features: A direct connection allows the internal display to utilize NVIDIA G-Sync, high refresh rates, and native color management tools that the iGPU cannot support.
