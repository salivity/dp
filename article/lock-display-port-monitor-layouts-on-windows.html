Lock DisplayPort Monitor Layouts on Windows

DisplayPort's Hot Plug Detect (HPD) feature frequently causes Windows to treat powered-down or sleeping monitors as completely disconnected, leading to rearranged desktop icons, misplaced application windows, and reset resolutions. This article covers the most effective third-party utilities and native Windows registry modifications available to lock monitor configurations, preserve window positions, and prevent DisplayPort disconnect issues.

The DisplayPort HPD Issue

When a DisplayPort monitor enters low-power sleep, it drops the Hot Plug Detect signal. Windows interprets this physical state change as a hardware removal, forcing all open windows onto the remaining active screen and dropping the display configuration into a fallback "simulated" mode. When the display wakes up, Windows often fails to restore the original layout.

Third-Party Utility Tools

1. PersistentWindows

PersistentWindows is a lightweight, open-source utility designed specifically to counter the DisplayPort sleeping bug.

  • How it works: It runs silently in the system tray, constantly tracking the positions of windows and monitors. When it detects a screen disconnect or wake-up event, it automatically restores windows to their exact pre-sleep coordinates.
  • Key advantage: It requires no configuration, uses negligible system resources, and does not require administrative privileges to manage window restoration.

2. Custom Resolution Utility (CRU)

CRU allows users to modify the EDID (Extended Display Identification Data) values directly in the Windows registry for graphics drivers.

  • How it works: You can remove low-resolution fallback modes and define an explicit native resolution profile for your specific DisplayPort monitor.
  • Key advantage: If Windows drops back to a default 1024x768 resolution when the monitor disconnects, CRU overrides driver defaults by deleting unwanted resolutions, effectively locking the system to display only your desired configurations.

3. DisplayFusion

DisplayFusion is an advanced multi-monitor management suite that includes monitor configuration locking.

  • How it works: Users can save "Monitor Profiles" and assign hotkeys or triggers to them. When monitors disconnect or reconnect, DisplayFusion can be configured to automatically re-apply the designated profile.
  • Key advantage: Beyond window restoration, it can force specific refresh rates, color settings, and desktop layouts via automated system event triggers.

4. MonitorKeeper

MonitorKeeper is a dedicated, single-purpose tool developed to stop Windows from rearranging desktops on multi-monitor setups after lock, sleep, or screensaver events. It creates a background watcher that enforces display geometry whenever power state changes occur.

Windows Registry Modifications: Locking Simulated Resolutions

When Windows loses the EDID signal from a sleeping DisplayPort monitor, it falls back to default simulated registry keys. You can edit these keys to match your monitor's native resolution, preventing windows from shrinking into the top-left corner upon wake.

  1. Press Win + R, type regedit, and press Enter.

  2. Navigate to the following path:

    HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\GraphicsDrivers\Configuration

  3. Look for keys beginning with SIMULATED_ or NOEDID_.

  4. Expand the target key, select the subfolder named 00, and locate the following DWORD values:

    • PrimSurfSize.cx (Width)
    • PrimSurfSize.cy (Height)

  5. Double-click each entry, switch the base to Decimal, and change the value to your native resolution (e.g., 2560 for cx and 1440 for cy).

  6. Expand the nested 00 subfolder directly beneath the first one, locate ActiveSize.cx and ActiveSize.cy, switch the base to Decimal, and input the same native resolution values.

  7. Restart the computer for changes to take effect.

Hardware Passthrough Alternative

If software utilities and registry overrides do not resolve the issue due to stubborn graphics driver implementations, a hardware-level solution is a DisplayPort EDID Passthrough Emulator (also called an EDID ghost adapter). Placed inline between your graphics card and the DisplayPort cable, it continuously feeds a steady EDID handshake to Windows, completely preventing the operating system from recognizing that the monitor has entered sleep mode.
