DisplayPort MDCV Metadata Support for HDR

DisplayPort is fully capable of conveying Mastering Display Color Volume (MDCV) metadata required for HDR calibration, starting with the DisplayPort 1.4 standard. By encapsulating Consumer Technology Association (CTA) InfoFrames within its transmission stream, DisplayPort allows source devices to send critical SMPTE ST 2086 static metadata directly to monitors and reference displays. This metadata provides the display with the reference monitor's color primaries, white point, and peak and minimum luminance boundaries, enabling accurate tone mapping and color management.

How DisplayPort Transmits MDCV Metadata

DisplayPort carries HDR metadata through Secondary Data Packets (SDPs) embedded in the blanking intervals of the video stream. Beginning with DisplayPort 1.4, VESA adopted support for the CTA-861.3 protocol, which standardizes the transmission of static HDR metadata.

Within this framework, the source device transmits the Dynamic Range and Mastering InfoFrame. This frame contains the SMPTE ST 2086 specification parameters that constitute the MDCV, including:

  • Display Primaries: The x and y chromaticity coordinates for red, green, and blue used by the mastering monitor.
  • White Point: The x and y chromaticity coordinates of the mastering display's white point (typically D65).
  • Luminance Range: The maximum and minimum mastering display luminance values, defined down to 0.0001 nits.
  • Content Light Levels: Maximum Content Light Level (MaxCLL) and Maximum Frame-Average Light Level (MaxFALL).

Relevance to HDR Calibration

For professional color grading and HDR calibration workflows, transmitting accurate MDCV metadata is crucial. Reference monitors rely on this data to determine whether they need to tone map incoming signals or if the signal fits entirely within the panel’s native color gamut and dynamic range.

If a display receives a signal without MDCV metadata, it often falls back to default assumptions (such as clipping bright highlights or applying generic tone curves), which degrades color accuracy. Because DisplayPort accurately conveys the mastering volume parameters, calibration hardware and software can profile the display based on the intended creative reference rather than unstandardized estimations.

Specification Versions and Limitations

  • DisplayPort 1.2 and Earlier: Lacks native packet architecture for CTA InfoFrames and cannot convey HDR or MDCV metadata.
  • DisplayPort 1.4: Standardizes static HDR metadata delivery (SMPTE ST 2086) via CTA-861.3, providing complete MDCV support.
  • DisplayPort 2.0 / 2.1: Maintains static MDCV transmission while expanding bandwidth and adding native support for dynamic metadata protocols (such as SMPTE ST 2094 for HDR10+), where color volume parameters adjust on a scene-by-scene or frame-by-frame basis.

Successful MDCV transmission also requires the operating system, graphics drivers, and output application to pass the metadata untouched via the graphics pipeline to the DisplayPort transmitter.
